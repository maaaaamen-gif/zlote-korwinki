# Złote Korwinki

Node.js/Express app hosted on Render. MongoDB Atlas stores submissions and votes; uploaded media is stored in MongoDB GridFS.

## Deploy on Render

1. In Render, choose **New → Blueprint** and connect this GitHub repository.
2. Render reads [`render.yaml`](./render.yaml) to create the web service.
3. Set `MONGODB_URI` to the connection string generated by Atlas for your cluster. Keep it secret and URL-encode special characters in the database user's password.
4. Set `MONGODB_DB` to `zlote_korwinki` if it is not already set by the Blueprint.
5. Deploy and use the `onrender.com` URL shown for the service. This app's API and static site are served by the same Node.js service.

The Atlas cluster must be running, and Atlas Network Access must allow the Render service to connect. For a hobby project, an Atlas IP access-list entry of `0.0.0.0/0` can be used if Render's outbound addresses cannot be restricted; use a dedicated database user with a strong password and access limited to this application's database.

Render Free web services spin down after inactivity and have an ephemeral local filesystem. The app stores uploaded media in MongoDB GridFS rather than relying on local disk.

## Local development

Copy `.env.example` to `.env`, fill in `MONGODB_URI` and `MONGODB_DB`, then run:

```sh
npm install
npm start
```

Run tests with `npm test`.
